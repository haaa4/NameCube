# V1.4-Beta-3(#p10#)
> [!Warning]
> **更新前须知**
>
> - 该版本将NET降级至6.0，可能会出现兼容问题，你可能需要安装[NET 6运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/thank-you/runtime-desktop-6.0.36-windows-x64-installer)，请在更新前备份好数据，若出现问题请回退至V1.3版本。
> - 由于权限管理配置方式更新，你可能需要重新设置相关内容
> 
## 新增功能
- **Windows 7**: 新增对 Windows 7 的支持，用户可以在 Windows 7 系统上运行 NameCube。
- **窗口与渲染**: 现在可以自定义主界面窗口的大小和位置，用户可以根据自己的需求调整布局。
- **更新**：安装程序可以自动检测是否安装NET6并提示用户安装，确保软件正常运行。
## Bug 修复
- 修复悬浮球拖拽偏移的问题
- 修复快捷键触发自动流程总是要显示主界面的问题
## 体验优化
- **主界面**：加速了界面渲染速度
- **更新**：优化了更新机制，减少了更新时的卡顿现象
## 回退的功能
- **自定义朗读**:请在设置-TTS使用
## 未来更新
- 即将支持32位系统
